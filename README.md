# Insurance Analytics & Prediction

An end-to-end insurance analytics project using **MySQL, SQL, Python, Machine Learning, and Power BI**.

## Project Overview

This project analyzes insurance policy, customer, premium, coverage, and claim data to generate business insights and build predictive models.

The complete workflow is:

**CSV Dataset → MySQL → SQL Analysis → Python & Machine Learning → Power BI Dashboard**

## Dataset

* **Records:** 10,004
* **Features:** 13
* **Domain:** Insurance Analytics

The dataset contains information related to:

* Customer demographics
* Policy types
* Premium amounts
* Coverage amounts
* Claims
* Claim status
* Policy dates

## Project Workflow

1. Imported insurance data from CSV.
2. Stored the data in MySQL.
3. Used SQL queries for data analysis and business insights.
4. Performed data preprocessing and analysis using Python.
5. Built machine learning models for prediction.
6. Created an interactive Power BI dashboard.
7. Analyzed insurance premiums, coverage, claims, policy types, and customer demographics.
